## Stack vs Queue Table

| Feature | Stack | Queue |
|---|---|---|
| Rule | LIFO | FIFO |
| Add operation | push() | enqueue() |
| Remove operation | pop() | dequeue() |
| View next item | peek() | peek() |
| First item removed | Most recently added item | Earliest added item |
